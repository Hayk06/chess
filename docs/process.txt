QMainWindow — your main application window
QStackedWidget — switches between your Welcome/Setup page and Board page
QWidget — base class for each page
QLabel — welcome text, player information, timer labels
QPushButton — "Start Game", side selection, etc.
QRadioButton + QButtonGroup — choose White / Black / Random
QComboBox — choose a timer preset such as 5+0, 10+0, 10+5
QSpinBox — useful if you want the player to choose minutes manually
QTimer — countdown clocks during the game
QGridLayout — very convenient for your 8×8 chess board
QVBoxLayout / QHBoxLayout — arrange the UI
QSizePolicy — useful for making the board resize nicely
